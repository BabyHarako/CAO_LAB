▸  Register & syscall cheat-sheet MIPS / SPIM conventions

Registers

$zero
hardwired to the constant 0
$a0–$a3
arguments passed into a syscall or subroutine
$v0
syscall service number going in; a return value coming out
$t0–$t9
temporary values, not preserved across calls
$s0–$s7
saved values, meant to persist across a subroutine call
$ra
return address, set automatically by jal

Syscall codes (in $v0)

1
print the integer in $a0
4
print the null-terminated string at the address in $a0
5
read an integer from input into $v0
10
exit the program

Addressing: offset($reg)

syntax
N($reg) means "the memory address stored in $reg, plus N bytes"
why 4?
each word is 4 bytes, so offsets 0, 4, 8… step through consecutive array slots
example
if $s0 points at fibs[0], then 4($s0) is fibs[1] and 8($s0) is fibs[2]
